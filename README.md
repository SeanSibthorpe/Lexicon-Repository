# Garage v2
The program is a menu-driven console application.

The menu is navigated by selecting menu options using keys 0-9 or numpad 0-9.
The Main Menu contains three functions. Exit, Add Garage and Manage Garage.
Add garage can only be done once. Manage Garage requires an existing garage.
The Manage Garage menu contains all the core functionality to managing the garage.

The program contains 8 classes.
An abstract Vehicle class that contains information shared by all vehicle types.
5 different classes that inherit from Vehicle (Car, Bus, Boat, Motorcycle, Airplane) and contain their own unique information.
A Program Class that handles the Main Menu.
And a Garage Class that handles the Manage Garage Menu.

Limitations - Contains only the required functionality of the assignment.
Feedback request: Input handling, Error handling.
